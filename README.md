# Pixel Interactive Animation

マウスの動きに合わせて、ドット絵のキャラクターが歩いたり走ったりするデスクトップアプリです。Java の AWT と `javax.sound.sampled` だけで作っています。

スコアや勝ち負けのあるゲームではなく、操作に反応して動きを眺めて楽しむトイアプリです。見た目はポケモンシリーズ（ポケットモンスター ルビー、ラティオスなど）をモチーフにしています。素材の扱いについては [NOTICE.md](NOTICE.md) を参照してください。

## 操作方法

| 操作 | 動き |
| --- | --- |
| ウィンドウ内にマウスカーソルを入れる | キャラクターが歩き出し、背景がスクロールする |
| ウィンドウの外にカーソルを出す | キャラクターが立ち止まる |
| カーソルをウィンドウの右半分 / 左半分に動かす | キャラクターが右 / 左を向き、その方向に進む |
| ウィンドウ内でドラッグする | キャラクターが走る（背景のスクロールも速くなる） |
| 画面下のモンスターボールをクリックする | ボールを投げる動作をして、ラティオスを呼び出す。もう一度クリックすると戻す |
| 画面上のタイトルロゴをクリックする | 効果音をランダムに再生する |

## 動作環境

- JDK 8 以上（標準ライブラリだけを使っており、追加のライブラリは不要です）
- 画面のある環境（AWT のウィンドウを表示します）
- 音声出力デバイス。起動時に効果音を読み込むため、音声出力デバイスがない環境では例外が発生して起動できません。

## ビルドと実行

```bash
git clone https://github.com/mimish0778/pixel-interactive-animation.git
cd pixel-interactive-animation

# コンパイル
javac -d build src/*.java

# 実行
java -cp build InteractiveAnimation
```

画像と効果音を `src/images/...`、`src/sounds/...` という相対パスで読み込んでいるため、`java` コマンドは必ずプロジェクトのルートディレクトリで実行してください。ほかのディレクトリで実行すると、画像や効果音が読み込めません。

600 x 600 ピクセルのウィンドウが開きます。ウィンドウを閉じると終了します。

## プロジェクト構成

```
.
├── src/
│   ├── InteractiveAnimation.java  メインクラス（ウィンドウ、描画、マウス入力）
│   ├── ClipProB.java              効果音ファイルを読み込むユーティリティ
│   ├── images/                    キャラクター、背景、モンスターボールの画像（GIF）
│   └── sounds/                    効果音（WAV）
├── docs/screenshots/              README 用のスクリーンショット
├── NOTICE.md                      素材の著作権に関する注意事項
└── LICENSE
```

描画は 1 つのスレッドでループしており、キャラクターの状態（立ち止まり、歩き、走り、投げ）に応じて、アニメーションの更新間隔と背景のスクロールを切り替えています。

## 素材について

画像と効果音には、ポケモンシリーズ（株式会社ポケモン / 任天堂 / ゲームフリーク）に由来する要素が含まれています。画像はポケモンシリーズをモチーフに描き起こしたもので、二次創作にあたります。素材を公開・再配布する前に、必ず [NOTICE.md](NOTICE.md) を読んでください。
