# Pixel Interactive Animation

マウスの動きに合わせてドット絵のトレーナーが歩いたり走ったりする、Java（AWT）製の小さなインタラクティブアニメーションです。モンスターボールをクリックすると、ラティオスが出てきて後ろをついてきます。

勝ち負けやスコアのあるゲームではなく、触って動きを楽しむおもちゃのようなものです。見た目はポケモン（ルビー・サファイア）をモチーフにしています。

## 動かし方

JDK 8 以上があれば、追加のライブラリなしで動きます。

```sh
javac -d build src/*.java
java -cp build InteractiveAnimation
```

画像と音声を `src/images/` `src/sounds/` からの相対パスで読み込んでいるので、`java` コマンドは **リポジトリのルートで** 実行してください。

## 操作

| 操作 | 動き |
|---|---|
| マウスをウィンドウに入れる | 歩き出す（背景がスクロール） |
| マウスをウィンドウの外に出す | 立ち止まる |
| ドラッグする | 走る |
| マウスをウィンドウの左半分／右半分に置く | 向きが変わる |
| モンスターボールをクリック | ボールを投げてラティオスを出す（もう一度で戻す） |
| タイトルロゴをクリック | 効果音がランダムに鳴る |

## ファイル構成

```
src/
  InteractiveAnimation.java  ウィンドウ、描画、マウス入力
  ClipProB.java              効果音の読み込み・再生
  images/                    スプライトと背景（GIF）
  sounds/                    効果音（WAV）
docs/screenshots/            README 用のスクリーンショット
```

アニメーションは専用スレッドで回していて、歩き・走りの状態に応じてコマ送りの間隔を変えています。スプライトは左右反転させて描くことで、1 枚の画像で両方向を表現しています。
